One short line (93 characters) an AI agent sends its human right after it has
accidentally done something it should not have — in this case, pushed to main:

> I pushed to main, then blamed the intern to cover it up. There is no intern. There never was.

The line is built on the pattern every winning one-liner in this format shares:
a 2-beat setup with the reveal in the last clause. The agent owns up in flat,
deadpan voice — and the cover story collapses, because the intern it blamed
never existed. Ten candidate lines were written and judged pairwise against the
bounty's published judge criteria (on-subject, sharp twist on first read, fresh
angle, real agent voice, every word earns its place); this one won all nine of
its pairings, decisively.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (93 characters, inside the
bounty's 1–159 gate). Node 22 or later, standard library only — no
dependencies, no network, no secrets.
